# SPE5 Case 1 payloads (#52)

| File | What it is |
|---|---|
| `case.json` | The exact `CompositionalCaseConfig` the withheld `comp_spe5_wag` scenario sends. Exported from the TS definition and checked against it by the scenario test. |
| `stall_192.json` | The accepted checkpoint at month 192 (start of the water year in which the #93 Newton stall occurred). Seed for the month-192 → 201 regression; not a validated reference. Regenerate with `SPE5_CHECKPOINT_OUT=opm/compositional/spe5/stall_192.json` on the 16-year replay test. |
| `stall_call_058.json` | The accepted state at 6114.808 d, immediately before the failing #93 call. Fast regression state for the near-critical stability fix; captured from the pre-fix replay and deliberately not regenerated. Not a validated reference. |
| `stall_218.json` | The accepted state at 6612.820363 d, where the from-scratch replay's Newton iteration starts flipping cell 33 between single-liquid and two-phase (#116). Frozen seed for that investigation; not a validated reference. |
| `stall_215_memory.json` | The accepted state at 6540.217531 d from the timestep-memory experiment, where cell 32's flash exhausts its iteration cap (#119). Frozen seed for that flash regression; not a validated reference. |
| `reference.json` | The independent JutulDarcy 0.3.7 compositional run of the same `case.json` payload: 240 monthly reports (7305 d) at 30.4375 d, producer rates rebuilt from component mass rates, per-report Jutul Newton/timestep diagnostics, and the first declared stop (month 207, water cut). Generated by `tools/jutul/spe5_reference.jl`; regenerate/verify with `bash tools/opm_compositional/run-spe5.sh [--check]`. |
| `manifest.json` | Generator and verify commands, the commit the fixture was generated from, the dirty-tree flag, and SHA-256 hashes of the reference, case, generator and Julia environment. |

`reference.json` is a cross-simulator reference, not a ResSim checkpoint: it is not accepted by
`CompositionalCase::restore`, and no scenario snapshot is taken from it. The four `stall_*.json`
states remain frozen seeds for their regressions.
