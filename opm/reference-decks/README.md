# OPM FIM reference decks

These are tracked, offline fixtures for convergence comparisons between the FIM/wasm presets and
OPM Flow. They are not product artifacts.

Each case directory contains:

- `CASE.DATA` — the Flow input deck, generated by the simulator (never hand-mapped);
- `manifest.json` — the ResSim invocation, generated-by marker and deck checksum. A manifest may
  also carry typed OPM expectations, but the generated decks deliberately do not: their gated
  baseline is the shared scorecard.

Validate a fixture without running a simulator:

```bash
node scripts/opm-reference-fixture-check.mjs --case gas-rate-10x10x3
```

Run the side-by-side baseline (Flow output is written outside the source tree):

```bash
scripts/opm-ressim-compare.sh --case gas-rate-10x10x3 --out-dir /tmp/opm-ressim
```

## Generated decks

`water-heavy-step1`, the three `water-pressure-*` decks and `gas-rate-10x10x3` are written by the
same `opm_small_direct.rs` deck writer as the rest of the cross-solver matrix. Regenerate them
with:

```bash
OPM_SMALL_DECK_DIR="$(mktemp -d)" OPM_SMALL_DECK_LAYOUT=legacy \
  cargo test --release --manifest-path src/lib/ressim/Cargo.toml --lib \
  opm_small_direct_write_decks -- --ignored
```

`OPM_SMALL_DECK_LAYOUT=legacy` sends the five wasm-preset cases to these top-level directories and
the rest to the temporary directory. The checksum in each manifest must be updated after a
regeneration; `opm-reference-fixture-check.mjs` enforces it.

The comparator discovers both these directories and `small-direct/`. Their current measurements
are rows in [`small-direct/scorecard.json`](small-direct/scorecard.json); the README tables there
are generated from the same comparator. The old hand-mapped SWOF/PVCDO notes (#21) are retired:
the deck now carries ResSim's own relperm/PVT tables, so there is no hand mapping left to gap.
